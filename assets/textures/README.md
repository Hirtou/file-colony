# Текстуры

Мебель (furn_*): у всех предметов «спина» (то, что упирается в стену) сверху картинки; для других стен игра поворачивает спрайт. Свет сверху-слева, обводка как у бочки.

Материалы стен (`<mat>`): wood (брёвна), stone (тёсаный камень), brick (кирпич), timber (фахверк), hut (серая потрескавшаяся, во мху).

Перегенерировать (детерминированно, повторный запуск даёт те же байты; `--collage путь.png` ещё рисует проверочные коллажи `путь.png` и `путь_rooms.png`):

    & "$env:LOCALAPPDATA\Programs\Python\Python312\python.exe" tools/make_textures.py
